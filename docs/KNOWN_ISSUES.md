# 已知问题

## 性能

- `qwen3:4b` 的多节点 Deep 推理在本地可能超过 10 分钟。
- 轻量跨论文流程已验证可在约 6 分钟完成，但仍不适合高频交互。
- UI 使用真实 spinner，不提供虚假百分比进度。

## 检索质量

- qwen embedding 的短查询可能落在默认相关度阈值 `0.25` 以下。
- 参考文献列表块可能与正文语义相似，跨论文流程会做保守过滤。
- Crossref 元数据可能缺少期刊、摘要或其他字段。
- 当前不包含 OCR，扫描版 PDF 可能没有可检索文本。

## Agent 行为

- Deep Mode 仍可能出现工具选择错误或过早结束。
- 完整 Deep Query Decomposition 实验在 1200 秒预算下曾超时。
- 轻量跨论文流程采用单次结构化生成；来源正确不保证科学结论正确。

## 评测

- 当前 Benchmark 规模较小。
- 参考答案和模型回答仍有大量 `pending_human_review`。
- Citation Validation 只检查引用 ID、来源映射和结构化页码，不验证科学含义。
- 不提供正式 Answer Accuracy。

## 发布

- 项目尚未声明自身开源许可证。
- 尚未配置 CI、远程部署或公开在线演示。
- 本地 PDF、Chroma 和原始运行日志不进入公开仓库。
